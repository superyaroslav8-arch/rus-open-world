# РУСЬ

**Открытый мир России**

Создай персонажа, выбирай животных-помощников (Гусь, Медведь, Лиса, Тигр, Лев, Попугай) или технику (дрон DJI, робот), рюкзаки (3D-принтер Bambu Lab, полицейский, спецназ и др.).

## Играть прямо сейчас

👉 **https://superyaroslav8-arch.github.io/rus-open-world/**

### Что происходит при открытии:
1. Заставка с медведем и названием **РУСЬ**
2. Загрузка мира — лис крутится клубком / бегает
3. Гусь появляется и подробно объясняет все функции на русском
4. Создание персонажа (цвет кожи, глаз, помощник, рюкзак)
5. Вход в открытый мир

Всё бесплатно. Всё на русском. Графика уровня GTA V / GTA VI (прототип).
